`hooks/register.tsx` 的关键实现：

- `session.start`（`register.tsx:117`）：`$.command.register({ name: 'background-tasks', ... })` → 立即 `await refresh($)`（第一帧就有数）→ `$.clock.every(10000, …)` 每 10 秒刷新 → `$.ui.open({ id: 'background-tasks', title: '后台任务' })`（打不开也被 catch 住，不影响启动）→ `next(e)`。
- `refresh()`（`register.tsx:85`）：跑 `$.process.run(["Tools/agents/status.sh", "--json"], { cwd: "/Users/zyx/Documents/GPXPointViewer", timeoutMs: 15000 })`；退出码非 0、JSON 解析失败、进程起不来、异常，全部压成一行 `{ status: 'error', error }` 写进 atom；函数永不抛，所以定时器不会崩。成功后 `update($, snapshot, () => 新快照)`，写入会让面板重画。
- 解析时**按 items 现算 N**：`items.filter(item => !item.aux).length`，`aux:true` 永远不计入任务数（不依赖 JSON 里的 `running` 字段）。
- `ui.render`（`register.tsx:147`，matcher `{ component: 'Pane', requestId: 'background-tasks' }`）：只用 `Box`、`Text` 两种元素，terminal / desktop 画同一棵树——
  - 第一行 `<Text bold size="heading">`：`现在有 N 个任务在跑`（N=0 为 `现在没有任务在跑`）+ ` · HH:MM:SS`；
  - 每个任务一行：`类型 · 名字 · 从 HH:MM 开始 · 详情`；
  - 没有任务时一行 `—`；
  - aux 项列在任务下面：`附带：类型 · 名字 · 从 HH:MM 开始 · 详情`，`dimColor`；
  - 最后一行 `dimColor`：`Claude API 台账合计 X 美元`；
  - 失败时整块显示 `读取失败：<error>`（`color="error"`），不崩、不空白。
- `command.run`（`register.tsx:140`，matcher `{ command: 'background-tasks' }`）：先刷新再 `$.ui.open` 重新打开面板，返回 `{ text: '后台任务面板已打开，每 10 秒自动刷新。' }`。
