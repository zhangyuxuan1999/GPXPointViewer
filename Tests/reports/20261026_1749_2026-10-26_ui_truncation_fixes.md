# 开发报告 · 2026-10-26_ui_truncation_fixes

## 改了什么（文件 + 要点）

### `GPXPointViewer/ContentView.swift`
- **滑杆标签列自适应**（`ContentView.swift:1398/1405/1413`）：`点大小 / 点透明 / 底图` 三行从固定 `.frame(width: 44)` 改为 `.frame(minWidth: 56, alignment: .leading).fixedSize(horizontal: true, vertical: false)`。英文 `Basemap` 不再折成 `Basema/p`；德文 `Deckkraft` 也顺带恢复为一行。
- **「打开 GPX」空间不足时退化为图标**（`ContentView.swift:1254`）：按钮标签改为 `ViewThatFits(in: .horizontal) { Label("打开 GPX", systemImage: "folder"); Image(systemName: "folder") }`，并保留 `.help("打开 GPX")` 与 `.accessibilityLabel`。补点模式及普通模式顶行都不再出现 `GPX…`。
- **断档候选分段控件独占一行**（`ContentView.swift:934-947`）：去掉标题行里的 `Spacer` + `.frame(width: 130)`，标题单独一行，`Picker` 放到下一行并 `.frame(maxWidth: .infinity)` + `.font(.caption)`。德文 `Alle | Straße | Vermutlich Bahn` 不再顶出窗口右边。
- **候选面板筛选行自动换行**（`ContentView.swift:949`，新 `WrappingHStack` 于 `ContentView.swift:2639`）：新增一个 `Layout` 实现，按控件理想宽度排布、放不下就换行，不再把 `Bereich einkreisen / Tunnelketten zusammenfassen / Nur Straßen füllen / Sprünge suchen / Per Karte einordnen` 压成 `Bere…/Per…` 等省略号。

### `GPXPointViewer/ChangeReviewWindow.swift`
- **顶栏从一行拆成两行**（`ChangeReviewWindow.swift:78` 起）：
  - 第一行：总览/详细分段 + 统计摘要（`lineLimit(2)` + 垂直 `fixedSize`，不再单行截断）+ 「等你选 N」。
  - 第二行：审阅底图菜单、浅色、叠加 OSM 隧道、隧道状态、生成进度，以及右侧的导航/落地按钮。
- 这样德文 `Übernommenes zeigen`、`Zurück zum Stapel`、`Übernehmen (0)…` 在 1000 pt 宽度下都有完整空间，不再互相挤压。
