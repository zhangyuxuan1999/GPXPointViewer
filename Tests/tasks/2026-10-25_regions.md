# 任务：地区统计（国家 / 省州 / 中国地级市）· 2026-10-25 · 第 1 轮

## 背景（这次改了什么、为什么）
对标《世界迷雾》新版的行政区卡片，新增「地区统计」窗口：到访国家列表 → 省/州 → 中国地级市，两种口径
（**点** = 落在该地区的轨迹点数 / 到访天数；**迷雾** = 该地区内解锁格子的面积 / 等级，口径与「迷雾统计」卡片同源）。
点一行主地图高亮边界并飞过去。查看点模式与迷雾模式可用，热力图模式隐藏入口。

改动文件：新增 `GPXPointViewer/RegionIndex.swift`（Regions.bin 读取 + 点归属）、`RegionStats.swift`（统计）、`RegionsWindow.swift`（窗口）；
`TrackStore.swift`（regionReport / regionsMode / regionSelection / ensureRegionReport / selectRegion）；`PointMapView.swift`（边界高亮覆盖层 + `rendererFor overlay`）；
`ContentView.swift`（控制面板「地区统计…」按钮）；`GPXPointViewerApp.swift`（Window 场景 `regions`）；`UITestHook.swift`（新钩子命令）；
`TrackData.swift`（`computeFogStats()` 拆出 `fogUnlockKeys()`，**迷雾统计的数字不应有任何变化**）；`Localizable.xcstrings`（新增 31 键三语翻译）。

**边界数据注意**：app 内置的 `GPXPointViewer/Regions.bin` 现在是 **0 个地区的占位文件**（真实边界数据待用户批准下载后再生成）。
所以真实轨迹在内置数据下全部「未归属」、窗口显示「没有内置行政区边界数据（Regions.bin）」——这是**预期**，不是 bug。
测功能逻辑用合成边界 `Tests/synth/regions_synthetic.bin`（两个假国家，经 0–4° 纬 0–2°），通过环境变量 `GPXPV_REGIONS_BIN` 注入
（文件必须放在沙盒容器里，见下）。

## 范围
- 要测：
  1. 地区统计回归脚本（确定性断言，含点口径/迷雾口径/选中高亮/.fwdb/内置占位数据）；
  2. 迷雾统计数字与地区统计迷雾口径的一致性（同一套解锁格键）——这是改到共用代码的地方；
  3. 窗口与钩子：开窗、口径默认值随显示模式、热力图模式、空数据、反复开关、换数据；
  4. 本地化：新键三语都有翻译，四语冒烟不回归（这次重新组装了整份字串表，**所有旧键的翻译也必须还在**）；
  5. 地图协调器冒烟（新加了覆盖层渲染回调和一个更新分支）：跑一个现有的、重度用相机/覆盖层的界面回归；
  6. 性能：大轨迹下报告耗时；
  7. 崩溃排查：整个过程不得出现新的 GPXPointViewer 崩溃日志。
- 不用测：补点/批量/乱跳/路网/视频导出/3D 热力（这次没碰）；合成数据套件（引擎检测逻辑没改）；Quick Look 扩展。

## 准备
- 构建：`xcodebuild -project GPXPointViewer.xcodeproj -scheme GPXPointViewer -configuration Release build`（增量，1–2 分钟；必须 BUILD SUCCEEDED）。
  测的是 `~/Library/Developer/Xcode/DerivedData/GPXPointViewer-*/Build/Products/Release/GPXPointViewer.app`（`Tests/ui/ui.py` 的 `app_source()` 自动选它；报告里写清 app 路径与可执行文件的修改时间）。
- 测试副本放 `Tests/ui/app.noindex/GPXPointViewer.app`，**一次只开一个**测试副本；/Applications 里用户正在用的那份**不要 kill**（脚本只 `pkill -f` 自己的副本路径）。
- 容器目录：`C=$HOME/Library/Containers/de.wayne.GPXPointViewer/Data/tmp`；钩子通信目录 `$C/uitest`；测试数据放 `$C/regions/`（回归脚本会自己拷合成边界、生成合成轨迹、拷 `data/2026.fwdb`）。
  真实轨迹自己拷：`cp data/Garmin_Roma_Da1.gpx "$C/regions/"`；`cp "data/2026.01.01-2026.12.31.csv" "$C/regions/"`。
- 手动启动测试副本的命令（钩子 + 合成边界 + 钉简体中文）：
  ```sh
  pkill -f Tests/ui/app.noindex/GPXPointViewer.app; sleep 1
  open -n --env GPXPV_UITEST_DIR=$C/uitest --env GPXPV_REGIONS_BIN=$C/regions/regions_synthetic.bin Tests/ui/app.noindex/GPXPointViewer.app --args -AppleLanguages '(zh-Hans)'
  ```
  不带 `GPXPV_REGIONS_BIN` 就是内置占位 Regions.bin。发命令：`python3 Tests/ui/ui.py "cmd1" "cmd2" …`（每个参数一条命令，结果按行返回）。
- 这次用到的钩子命令：`open <路径>`（GPX/CSV；`.fwdb` 目录也行）、`regions`（开地区统计窗口）、`regionsmode points|fog`、`regionstate`（JSON）、
  `regionselect <id>|off`、`regionlookup <lat> <lon>`、`fogstats`（迷雾统计卡的数字 JSON）、`set fogMap 0/1`、`set heatMap 0/1`、`windows`、`info`、
  `shotviewwin <窗口标题子串> <png 绝对路径>`、`shotview <png>`、`state`。
- **锁屏提示**：用户的屏幕可能锁着（`python3 Tests/ui/ui.py info` 里 `front=loginwindow`）。锁屏时 `shotwin`/`shot` 全白、MapKit 相机动画不走、
  `shotviewwin` 只能看到布局块（文字常渲不出来）。遇到这种情况把现象写进报告的「没做到的项目」，**不要当作功能失败**。

## 测试项（每项给命令 + 期望）
1. **回归脚本** — `python3 Tests/ui/run_regions_stats_tests.py` — 期望最后一行 `== 65/65 通过`。把每条 FAIL 原样抄进报告。
   脚本结尾会关掉测试副本。
2. **迷雾统计 ↔ 地区统计一致性（合成轨迹）** — 手动启动（带合成边界），`open $C/regions/synthetic_regions_track.gpx`（脚本第 1 项生成的，在容器里），
   `set fogMap 1`，`regions`，等 2 秒，`regionsmode fog`，`fogstats` 与 `regionstate`：
   期望 `fogstats.ready=true` 且 `fogstats.cells == regionstate.totalCells`（都应是 1013）；`regionstate` 里两国 km² 之和 + 未归属格面积 ≤ `fogstats.km2`；
   `fogstats.km2` 在 0.09 ± 0.01 km²、`level` 为 4。
3. **一致性（真实轨迹 Garmin）** — 同一副本 `open $C/regions/Garmin_Roma_Da1.gpx`，等 `state.points` 稳定（约 1 万点），`regions`、`regionsmode fog`、
   等 ready，`fogstats` 与 `regionstate`：期望 `cells == totalCells`（> 0），`unassignedCells == totalCells`（合成边界不覆盖意大利）、`countries` 为空；
   `regionsmode points` 后 `unassignedPoints == totalPoints == state.points`。
4. **一致性（.fwdb 存档）** — `open $C/regions/2026.fwdb`（脚本第 1 项已拷进容器），等 `regionstate.modes == ["fog"]`，`regions`，等 ready，`fogstats`：
   期望 `fogstats.cells == regionstate.totalCells`（存档直读，应立即 ready）。
5. **窗口默认口径随显示模式** — 新开副本（合成边界），`open` 合成轨迹，先 `set fogMap 0` 再 `regions` → `regionstate.mode` 应为 `points`；
   关掉窗口没有钩子，直接 `set fogMap 1` 再 `regions`（窗口已开着，不重新算默认值）→ 用 `regionsmode fog` 手动切，再 `set fogMap 0` →
   mode 保持 `fog`（用户手动选过就不自动改）。再新开副本：先 `set fogMap 1`、`open` 合成轨迹、`regions` → mode 应为 `fog`。
6. **热力图模式** — `set heatMap 1` 后 `shotview $C/regions/heat.png`、`set heatMap 0` 后 `shotview $C/regions/noheat.png`：
   期望热力图下控制面板没有「地区统计…」按钮，关掉后又出现（锁屏时文字可能渲不出来：那就比较两张图控制面板的按钮行数量差异；仍看不出就记「无法验证」）。
   `set heatMap 1` 时 `regions` 命令依然能开窗口（钩子绕过按钮）——不算 bug，但报告写明。
