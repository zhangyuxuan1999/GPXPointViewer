# 行程／每日摘要使用指南（当前开发分支）

本指南说明当前开发分支（`summary-v1`）的统计规则与使用方式。既有摘要验收状态以 [每日／行程摘要验收记录](journey-summary-acceptance.md) 为准；日期导航与持久化的新构建、实际 UI 和跨进程结果待 `docs/journey-summary-date-persistence-acceptance.md` 记录。本文不是发布通过声明。

## 打开、日期、来源与时区

控制面板的「每日与行程摘要…」按钮或菜单栏「窗口」中的同名命令打开摘要窗口。主面板已明确选择一天时，点击入口直接打开该日；窗口已打开时再次点击入口会更新到主面板新选的日期。

未选日期、只选年或月、或范围包含多日时，摘要不会自动挑一天：窗口顶部固定显示可键入年／月／日的日期控件和「查看」按钮，先选择年月日，再点「查看」或按回车。没有记录的日期会明确提示「该日期没有记录」，保留该日期，不跳到邻近有记录的日。

窗口内可选择来源文件、时区和“每日／行程”视图。来源下拉列出当前载入的文件，默认选当前单文件；多文件时选第一个仍存在的文件。摘要按所选来源文件的全部记录计算，整源缓存只用于计算，浏览内容始终跟随入口或控件所选的那一天，不跟随主地图的时间筛选。不同来源文件分别报告，不跨文件相加，也不自动选主记录或融合设备。查看摘要不会自动改变主地图筛选，只有「在主地图上查看」按钮会改变它。

时区可选本机、UTC 或指定 IANA 时区。本机模式在发起计算时捕获系统时区，报告显示实际 IANA 标识；它只是计算时区，不称为“轨迹所在地时间”。指定时区必须已知或校验通过，不会静默回退。换时区会改变自然日分桶和跨午夜分摊，但不改变同一行程的总距离。

## 每日、行程与详情

“每日”正文只展示所选日期的完整指标，按该时区的自然日分组，日界用 Gregorian 日历计算；夏令时日可为 23 或 25 小时。“行程”页左侧只列出所选日期关联的行程，右侧显示完整行程详情；行程按硬源段和 30 分钟记录空白分段，跨午夜行程仍是一行，保持完整距离、时间与统计，不按午夜或所选日截断，不同源段绝不补连线。孤立带时间点也有行程，但距离、海拔和交通候选不可用。

点击一行只选择详情，不会自动改变主地图；只有“在主地图上查看”会改变筛选。单点行跨度为 0，会提示“仅一个记录点”。日期未知的点单列“日期未知：N 点”，不塞进某一天，也不虚构日期、速度或时长。两次记录相隔一周，不会生成中间六天的 0 公里空日；只有含有效带日期点或合格边贡献的日期才有行。

## 距离与时间

只处理同一源文件、同一源段内拓扑相邻的边：坐标和时间有效、时间严格递增、时间差不超过 5 分钟（300 秒）、球面速度不超过 1200 km/h。超过 5 分钟的间隔不凭直弦宣称覆盖路线；记录空白达到 30 分钟（1800 秒）时开始下一行程。

| 指标 | 含义 |
|---|---|
| 记录折线 | 两端均为记录位置的合格边长度之和，不是“真实路程”。 |
| 补点估算 | 至少一端为本会话合成位置的边，单独统计。 |
| 距离不可计算 | 无合格边时显示不可计算，不是 0 km；同时显示排除边数和未覆盖时间。 |
| 跨度 | 最早到最晚贡献的间隔；日行不固定为 24 小时。 |
| 观测间隔 | 两端均为未改写、非合成位置的合格边时间并集。 |
| 估算时间 | 含合成或改时端点的边时间，扣除已观测覆盖；重叠时观测优先。 |
| 未覆盖时间 | 跨度减去观测与估算后的未知部分，只在首末贡献之间。 |
| 移动估计 | 观测边中速度大于 1 m/s 的时间并集，不是停留检测。 |
| 低速间隔 | 观测间隔减去移动估计，不等于确认停留。 |

“未覆盖时间”只统计整行首末贡献之间，不把当天其余时间都算漏记，也不代表全天丢失。各行程时长之和未必等于每日时长，反之亦然：时长按区间并集计算，重叠不重复累加。跨 30 分钟边界的空白不属于任何行程，同一行程内的空白仍会体现在其跨度中。

跨午夜的合格边按时间比例把距离、边时长和爬升贡献分到两天；这是分配假设，不声称真实匀速。午夜时刻的点只计入后一天，边的前一段仍归前一天。

单文件含多个时间重叠的源段时，距离按各段记录折线分别累计，可能重复；时长取并集，不超过跨度。界面会提示“源段时间重叠，距离可能含重复记录”，不自动去重。

## 爬升、下降与地区

爬升和下降只在合格记录位置边上按断点分链：五点滚动中位数抑制孤立尖峰，再以 3 米垂直迟滞累加。只有海拔边覆盖率至少 80% 且至少两条海拔边时才发布并标“滤波估算”，否则不可用。它不保证真实高程，不按缺失比例外推；采样率也会影响结果，3 米以下起伏或狭窄山峰可能被抑制。

地区由离线边界索引逐点归属，分“记录位置到访”和“补点经过（估算）”。改时点的地理证据仍属记录位置，但日期归属是估算。没有落点的国家不推断为到访，未归属点单独计数；索引缺失时地区字段整体不可用，不是“0 个国家”。不猜跨境边的越境位置、地区内里程或停留时长。

## 交通方式

自动结果只是速度候选，始终标“仅按速度，未确认”，不会自动选中。只有观测移动时间至少 120 秒且至少 5 条移动边才给候选；速度不能断言“这是火车”或“这是步行”。合成和改时速度不参与候选。

可在详情手动指定未知、步行、骑行、公路、铁路、航空或水路，也可恢复自动候选。手动模式只保存在本会话，不写入项目；同一来源只切换摘要时区会保留手动选择；切换来源、更换或编辑轨迹、清空数据会清除。每日行只展示当天重叠行程的模式集合，不生成唯一全天交通方式，也不按候选分配精确里程。

## 在主地图上查看与清除筛选

“在主地图上查看”只在单文件模式、主地图轨迹与报告一致，且没有删除事务、补点、批次预览或回放时可用。每日行筛选完整自然日；行程行使用最后时刻的下一可表示值，以包含最后一点。经度跨度不超过 180° 时才请求相机；跨日界线宽范围只筛时间，不飞到地球另一侧。重叠或对比模式仍可浏览摘要，按钮会说明暂不支持，不会悄悄切换显示模式。

主地图时间筛选区会出现摘要专用块，显示准确开始／结束时间、来源、摘要时区，以及“清除摘要筛选”。清除后恢复完整记录和原来的“全部”模式；摘要自身筛选不会反过来成为摘要的新输入。

## `.fwdb` 与暂不支持

`.fwdb` 存档没有逐点真实时间和连续路线，页面会明确提示无法计算每日／行程摘要，也不从区块修改时间推导日期、距离或交通方式。摘要暂不提供 CSV 导出、手动合并／拆分行程、多设备融合或项目持久化，不能宣传为已支持。
