# 世界迷雾存档：新版（2026_fog_new_db，带行政区功能的版本）与旧版（2026.fwdb）对比 · 2026-10-25

结论：**区块文件格式没有变**，app 现有的解析器（`FogArchive.swift`）直接可用；行政区数据不在存档里。

- 文件名/区块编码一致：文件名去掉前 4 后 2 字符，密码表 `olhwjsktri` → 区块号，x = num % 512，y = num / 512；zlib 流；
  解压后 = 128×128 的 uint16 LE tile 索引表（32768 字节，1 基）+ 每个 tile 515 字节（512 字节 64×64 位图 MSB 先 + 3 字节尾部）。
  新旧共 135 个区块文件全部严丝合缝地符合这一布局（84 新 + 51 旧）。
- 目录结构：zip 里仍是 `Sync/` 子目录，解压出来的目录是平铺的；加载器两种都认。
- 内容差异（同一用户数据的新旧快照）：51 个共有区块里 29 个字节相同、22 个变大（多了 tile）；33 个新区块；解锁格总数 802,304 → 1,209,290。
  若干区块少了一个 tile 但格数相同——新版似乎会丢掉空 tile。
- 每 tile 的 3 字节尾部是逐 tile 的小值（如 `00 00 81`、`00 01 01`），不是行政区信息。
- **存档里没有任何行政区/边界数据**：世界迷雾的行政区卡片是 app 端用自带的边界数据算出来的，所以我们也要自带边界（见 `regions-design.md`）。
